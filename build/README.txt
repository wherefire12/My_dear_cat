MY DEAR CAT — how to use
========================

  • Grab the cat with the mouse and drag it anywhere; it remembers the spot.
  • Clicking the cat = petting it (hearts float up).
  • The buttons underneath: Pet · Feed · Clean · Party (Party throws confetti across the whole screen).
  • When the mouse comes close, the cat turns and looks at you.
  • When left alone, it rests in different poses on its own.
  • Clicks go through the transparent parts of the cat, so desktop icons behind it still work.
  • It comes back by itself every time the computer starts.

SETTINGS — right-click the cat icon next to the clock
  Show/hide · Size · Always on top · Sound · Buttons ·
  Start with Windows · Reset position · Open videos folder · Quit

UNINSTALL
  Windows Settings → Apps → "My Dear Cat" → Uninstall.
